Basic Inventory Management System

Build a simple web application to manage products and their stock quantities.

Features:
1. Add products with name, price and quantity.
2. View all products in a table.
3. Edit product details.
4. Delete products.
5. Update stock quantities.
6. Search products by name.
7. Display a low-stock warning when quantity is below 5.
