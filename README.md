Basic Inventory Management System

Build a simple web application to manage products and their stock quantities.

Features:
1. Add products with name, price and quantity.
2. View all products in a table.
3. Edit product details.
4. Delete products.
5. Update stock quantities.
6. Search products by name.
7. Display a low-stock warning when quantity is below 5.

Generated by the Quorq AI SDLC platform. Two applications, one repository:

- **`frontend/`** -- the approved app design as a Vite + React SPA. Every screen
  was reviewed and approved, and runs on seeded sample data.
- **`backend/`** -- a FastAPI service. No architecture had been approved
  when this repository was created, so it starts with its health check and
  nothing else.

## Running it

```bash
cd frontend
npm install
npm run dev
npm test          # unit tests (Vitest)
npm run lint       # ESLint
npm run format     # Prettier
```

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
pytest
ruff check .
ruff format .
```
